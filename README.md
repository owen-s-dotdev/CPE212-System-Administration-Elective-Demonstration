## 👨‍💻 About This Repository

This repository contains the **technical outputs, configuration files, automation scripts, and system administration artifacts** developed throughout the System Administration 2 course.

The repository serves as the technical companion to the **Automating Server Management Group Portfolio**.

> 📄 **Documentation:** The portfolio website contains the PDF documentation and activity evidence.  
> 🧰 **Technical Files:** This repository contains the actual configuration files, playbooks, scripts, and other implementation files.
